# MicroTransponder / Mobia Medical, Inc.

> MicroTransponder, Inc. was renamed Mobia Medical, Inc. on 2026-02-24. It is a medical
> device company that develops the FDA-approved Vivistim Paired VNS System — an
> implantable vagus nerve stimulator paired with rehabilitation therapy to reduce
> upper-extremity motor deficits in chronic ischemic stroke survivors. It is not a
> software vendor and runs no developer program.

Generated by API Evangelist on 2026-08-26 from the company's own public surface. The
provider does not publish an llms.txt; https://www.mobia.com/llms.txt returns HTTP 404.

## What this company does and does not publish

- No developer portal, no API documentation, no API reference, no getting-started guide.
- No OpenAPI, Swagger, AsyncAPI, GraphQL SDL, gRPC .proto or WSDL contract anywhere on
  any host it controls. All discovery paths were probed and missed.
- No SDKs or client libraries in npm, PyPI or any public registry; no GitHub organization.
- No status page, changelog, deprecation policy, SLA, sandbox, CLI, webhooks, Postman
  collection, security.txt, agent card or api-catalog.
- No API pricing or plans. The commercial model is a device sold to hospitals, with
  patient access through Medicare and commercial reimbursement.

## The one machine-readable surface that does exist

The corporate WordPress site serves a REST API and, unusually, an OAuth-protected Model
Context Protocol endpoint. This is site CMS infrastructure, not a Vivistim product or
clinical device API. Treat it accordingly.

- REST root: https://www.mobia.com/wp-json/ — 320 routes across 22 namespaces
- Content namespace: wp/v2 (posts, pages, media, `news` press releases, `team`,
  categories, tags, users, comments). Anonymous GET works; writes require WordPress
  credentials.
- Pagination: `page`, `per_page` (max 100), `offset`; `X-WP-Total`, `X-WP-TotalPages` and
  a `Link: rel="next"` header.
- Error envelope: `{"code": "...", "message": "...", "data": {"status": n}}` — not RFC 9457.
- MCP endpoint: https://www.mobia.com/wp-json/mcp/mcp-oauth-server (JSON-RPC, HTTP 401
  anonymous). `tools/list` requires an OAuth token; the tool set is not public.
- MCP endpoint: https://www.mobia.com/wp-json/mcp/mcp-adapter-default-server (HTTP 401
  anonymous, WordPress credential auth).
- WP Abilities: https://www.mobia.com/wp-json/wp-abilities/v1/abilities
- OAuth 2.0 authorization server metadata (RFC 8414):
  https://www.mobia.com/.well-known/oauth-authorization-server
  — authorization_code + refresh_token, PKCE S256, single scope `mcp`.
- OAuth 2.0 protected resource metadata (RFC 9728):
  https://www.mobia.com/.well-known/oauth-protected-resource
- The product site https://www.vivistim.com/ also runs WordPress
  (https://www.vivistim.com/wp-json/, 264 routes) but exposes no MCP namespace, and it
  answers HTTP 200 with a "404" HTML shell for every unknown path — do not trust a 200
  from that host as evidence a document exists.
